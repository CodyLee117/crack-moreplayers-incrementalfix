CRACK - More Players (8-player crews), no mod manager needed

1. Close CRACK.
2. Unzip this folder anywhere, then double-click CRACK-MorePlayers-Setup.bat.
   If Windows says "Windows protected your PC", click More info > Run anyway.
3. Pick 1 to install. It finds CRACK through Steam and downloads BepInEx 5.4.2305 and More Players 0.5.2 from thunderstore.io, and the More Players Incremental Fix 0.1.0 from GitHub (all checked by SHA-256).
4. Launch CRACK from Steam as usual.

Run the same file again to:
  2 = Disable (play vanilla: achievements and ranked)
  3 = Enable
  4 = Uninstall (removes the mod; removes BepInEx too if this tool installed it)

Everyone in the lobby needs both, same versions (the lobby refuses a mismatch). Needs internet for the install. Windows 10/11 only.
Mod by khovanet: https://thunderstore.io/c/crack/p/khovanet/More_Players/
Incremental Fix: https://github.com/CodyLee117/crack-moreplayers-incrementalfix
The installer checks that repo for a newer version of itself when it starts, and asks before updating.
